# Desechables Guillén - Landing Page

Landing page moderna y responsiva para Desechables Guillén: comercialización y distribución de productos desechables, contenedores de alimentos, delivery y línea biodegradable.

## 🚀 Tecnologías

- **React 19**
- **Vite**
- **TypeScript**
- **Tailwind CSS v4**
- **Lucide React** (iconos)

## 📦 Instalación y Desarrollo

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar el servidor local de desarrollo:
   ```bash
   npm run dev
   ```

3. Compilar para producción:
   ```bash
   npm run build
   ```

4. Previsualizar la versión compilada:
   ```bash
   npm run preview
   ```
