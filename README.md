# Desechables Guillén - Landing Page

Landing page moderna y responsiva para Desechables Guillén: comercialización y distribución de productos desechables, contenedores de alimentos, delivery y línea biodegradable.

## 🚀 Tecnologías

- **React 19**
- **Vite**
- **TypeScript**
- **Tailwind CSS v4**
- **Lucide React** (iconos)

## 📦 Instalación y Desarrollo

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar el servidor local de desarrollo:
   ```bash
   npm run dev
   ```

3. Compilar para producción:
   ```bash
   npm run build
   ```

4. Previsualizar la versión compilada:
   ```bash
   npm run preview
   ```

## 🌐 Despliegue en Vercel

El proyecto incluye `vercel.json` configurado para Vite y SPAs.

### Opción 1: Desde la Web de Vercel (Recomendada)
1. Entra a [vercel.com](https://vercel.com) e inicia sesión con tu cuenta de GitHub.
2. Da clic en **Add New...** > **Project**.
3. Importa el repositorio **`Mahia113/desechables_ladingpage`**.
4. Vercel detectará la configuración automáticamente (Framework: *Vite*, Build: *npm run build*, Output: *dist*).
5. Da clic en **Deploy**.

### Opción 2: Vía Vercel CLI
```bash
npx vercel --prod
```
